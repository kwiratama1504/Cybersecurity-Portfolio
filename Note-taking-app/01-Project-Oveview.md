# Project Overview

## Note-Taking App

The project involved developing a utility note-taking application for Android.

The main goal was to build an easy-to-use application for creating, editing and organising notes while keeping the data stored locally.

## Main Features

- Add new notes
- Edit existing notes
- Delete notes
- Search notes
- Pin and unpin notes
- Store notes persistently using Room Database

## Application Flow

```text
Main Screen
    ↓
Create / Select Note
    ↓
Add or Edit Note
    ↓
Save to Room Database
    ↓
Display Notes
```

## Development

The application was developed using **Kotlin** in **Android Studio**.

The project uses Android activities and XML layouts for the user interface, with **Room Database** for local data storage.
