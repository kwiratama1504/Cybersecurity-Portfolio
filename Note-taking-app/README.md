# Note-Taking App

A university Android application developed for **CP3406 Mobile Computing**.

The app is a simple note-taking utility that allows users to create, edit, delete, search and store notes locally.

## Features

- Create notes
- Edit notes
- Delete notes
- Search notes
- Pin notes
- Persistent local storage using Room Database
- Simple RecyclerView-based interface

## Tech Stack

**Kotlin · Android Studio · Room Database · SQLite · Material Components**

## What I Learned

This project gave me practical experience building an Android application and connecting the user interface to a database.

I was comfortable working on the user interface because I had previous experience with Android layouts and Kotlin. Building the main functionality and connecting the application to the database also helped me understand how the different parts of the application work together.

One of the main challenges was working with **Room Database**, especially when dealing with database schema changes, versioning and migration. I had to look more closely at the Room documentation and troubleshoot the issues systematically.

After resolving these problems, I gained a better understanding of how Room manages application data.

For future development, I would like to learn more about **multithreading, database optimisation and application testing**. Overall, this project gave me a useful foundation in Android and mobile application development.
