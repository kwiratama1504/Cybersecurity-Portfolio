# Ethical Hacking

An individual university project completed for **CP3414 Ethical Hacking** at James Cook University.

The project involved performing a vulnerability assessment using **Nessus Advanced Scan** against a controlled lab network.

## Project Focus

- Vulnerability assessment
- Network security
- Vulnerability analysis
- Risk prioritisation
- Security remediation

## My Work

I performed the assessment individually, including:

- Conducting the Nessus vulnerability scan
- Analysing the scan results
- Identifying security vulnerabilities
- Assessing vulnerability severity
- Documenting findings
- Recommending remediation

## Tools

**Nessus · CVSS · NIST NVD**
