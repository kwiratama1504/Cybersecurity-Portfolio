# Project Overview

## Ethical Hacking

**Project Type:** Individual University Project

This project involved performing a vulnerability assessment against a controlled lab network.

The assessment used **Nessus Advanced Scan** to identify security weaknesses across different systems and services.

## Objectives

- Identify vulnerabilities
- Analyse security risks
- Prioritise findings based on severity
- Recommend appropriate remediation
