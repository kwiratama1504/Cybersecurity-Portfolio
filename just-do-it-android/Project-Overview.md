# Project Overview

## Just Do It — Android To-Do List App

A university Android application developed for **CP3407 Advanced Software Engineering**.

The project focused on designing and developing a simple to-do list application for managing everyday tasks.

### Built With

- Kotlin
- Android Studio
- Room / SQLite
- MVVM
- Figma
- Miro

### Key Features

- Task management
- Priorities
- Due dates
- Reminders
- Task completion
- Categories
- Offline access
