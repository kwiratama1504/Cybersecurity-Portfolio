# Just Do It — Android To-Do List App

A university Android application project developed for CP3407 Advanced Software Engineering.

The project focused on creating a simple task-management app for organising tasks, priorities, due dates, reminders and categories.

## My Role

I worked on this project as the **Project Manager and UI Designer**.

- Coordinated project planning and team input
- Helped organise the project scope and user stories
- Designed the application's user interface and overall layout
- Worked with the team to turn requirements into the app's planned screens and workflow

## Main Features

- Task creation and organisation
- Task completion tracking
- Due dates and reminders
- Priority levels
- Notes and descriptions
- Sorting and filtering
- Offline access

## Technical Overview

The application was developed for Android using **Kotlin**.

The project used an **MVVM (Model-View-ViewModel)** architecture, with **Room** used as the persistence layer over SQLite.

The project structure included components such as:

- ViewModels
- Repositories
- DAOs
- Models
- Adapters
- Database components

## UI Design

I worked on the application's interface and overall layout.

The main screens included:

- Intro page
- Home page
- Add-task page
- Completed-task page

The goal was to keep the interface simple and easy to use for everyday task management.

## Project Planning

The team used user stories, estimation, priorities and iteration planning to organise the development process.

**Miro** was used for collaboration and project planning.

## Tools & Technologies

**Kotlin · Android Studio · Room · SQLite · Figma · Miro**
