# Unity-Technology-Bug-Bounty
A university security assessment based on the Unity Bugcrowd program. The project involved reconnaissance, scanning, endpoint discovery and manual web application testing within an assigned scope.

## What I Worked On
- Reconnaissance — Subdomain enumeration using Subfinder
- Scanning — Technology identification using WhatWeb
- Enumeration — Endpoint discovery using FFUF and Bash automation
- Manual Testing — Web traffic analysis and access control testing using Burp Suite

## Methodology
1. Reconnaissance
2. Technology Scanning
3. Endpoint Enumeration
4. Manual Web Testing
5. Vulnerability Analysis
6. Reporting

## Tools Used 
- Burp Suite - Intercept and analyse web traffic.
- FFUF - Discover hidden endpoints.
- Subfinder - Find subdomains.
- Nmap - Scan ports and services.
- Whatweb - Identify web technologies and server information.

## Project Details
1. Reconnaissance - 1,623 subdomains identified and 371 prioritised for further analysis.
2. Technology Identification - Identified web technologies and security controls.
3. Endpoint Discovery - Automated endpoint enumeration across selected subdomains.
4. Manual Testing - Analysed HTTP requests, responses and HTTPS behaviour.

## What I learned 
This project gave me more experience with the way penetration testing is actually carried out, especially the process of going from reconnaissance to finding and testing potential vulnerabilities. It also helped me get more comfortable with Burp Suite, FFUF and other tools, as well as documenting findings and thinking about how they could be fixed.
